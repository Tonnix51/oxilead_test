# OrderImport

Projet de départ du test technique. Il compile et s'exécute tel quel, sans base de données ni configuration :

```bash
dotnet run
```

Par défaut, le programme importe `sample-orders.csv` (fourni). Vous pouvez aussi passer un autre chemin de fichier en argument :

```bash
dotnet run -- chemin/vers/mon-fichier.csv
```

Consultez le sujet du test (PDF) pour les consignes et les livrables attendus.
